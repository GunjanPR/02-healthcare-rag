# Evaluation report: Healthcare RAG vs the BM25-only baseline

Generated by `make eval` on 2026-10-03 04:50 UTC. Numbers below are measured; nothing is estimated.

## Setup

- **Questions:** 159 in `eval/qa/questions.json`: 139 answerable (14 per topic, 13 for hypertension), each written from one passage sampled from the corpus, plus 20 out-of-scope questions the corpus cannot answer.
- **Split:** dev = every third question (53), used only to choose the abstention threshold; **test = 106** (92 answerable, 14 out of scope). All tables below are on test.
- **Corpus:** 500 PMC OA articles (CC BY/CC0), 8,369 chunks; see the README.
- **Models:** generation `llama3.2` via the LLM gateway (temperature 0, cache bypassed); embeddings `nomic-embed-text` via the gateway; reranker `ncbi/MedCPT-Cross-Encoder` on cuda.
- **Hardware:** Acer Nitro V 15, i5-13420H, RTX 4050 Laptop GPU 6 GB on AC power over USB-C (GPU power limit 20 W of a 60 W default). Ollama 0.35.0 native on the GPU (llama3.2 3B, nomic-embed-text), MedCPT reranker on the same GPU (fp16), gateway on the host, OpenSearch 2.17.1 (512 MB heap) and Qdrant 1.19.1 in Docker Desktop.
- **Host:** Windows 10.0.26200, Python 3.11.9

## How to read this

- Keyword grading: an answer is correct when every keyword group of the reference appears as a whole term. It does not catch a right answer phrased with other words, and it gives no credit for a refusal on an answerable question.
- Faithfulness: the original judge was the 3B model that writes the answers, and a manual check of 20 of its verdicts (`eval/qa/judge_audit.json`) found 7 of its 10 NO verdicts wrong. The qwen2.5:7b row comes from `python -m healthcare_rag.judge` (2026-10-19), a judge from another model family that agrees with those 20 labels 95% of the time (kappa 0.83). Audit, raw outputs and a hand check of every judge/keyword correctness disagreement: [benchmarks/2026-10-19-faithfulness](benchmarks/2026-10-19-faithfulness/README.md).
- Latency is client-side and sequential on one laptop GPU shared by generation, embeddings and the reranker. Cost is $0 because the gateway prices the local Ollama backend at zero; token counts are recorded to price other backends.
