# Faithfulness and correctness judging, test split (2026-10-19)

Measured on the answers of the 2026-10-03 test run (`eval/results/answers.json`), with the
second-pass judge in `src/healthcare_rag/judge.py`. The JSON files here are the unedited
outputs of the three commands below.

**Setup:** Acer Nitro V 15 on AC power (Windows `BatteryStatus` 2 for the whole run), RTX 4050
Laptop 6 GB. Ollama 0.35.0 serving `qwen2.5:7b-instruct` through the LLM gateway (project 01);
the answers were generated by `llama3.2` (3B), so the judge is from another model family and
twice the size. NLI scorer `cross-encoder/nli-deberta-v3-base` on CUDA.

```
python -m healthcare_rag.judge audit                                          # 160 s
python -m healthcare_rag.judge faithfulness eval/results/answers.json --scorer judge  # 672 s
python -m healthcare_rag.judge correctness eval/results/answers.json --split test     # 187 s
```

## 1. Which faithfulness scorer can be trusted? (`faithfulness_audit.json`)

Each scorer against the 20 hand labels in `eval/qa/judge_audit.json` (17 faithful, 3 not).

| Scorer | Agreement | Cohen's kappa | Faithful matched | Unfaithful matched |
|---|---|---|---|---|
| llama3.2 judge (the generator judging itself; used before) | 0.65 | 0.30 | 10/17 | 3/3 |
| Lexical support (token overlap >= 0.6) | 0.80 | 0.49 | 13/17 | 3/3 |
| NLI, nli-deberta-v3-base (entailment p >= 0.5) | 0.30 | 0.06 | 3/17 | 3/3 |
| **qwen2.5:7b-instruct judge** | **0.95** | **0.83** | **16/17** | **3/3** |

Only the qwen judge is close to the hand labels, so it is the only scorer whose rate is
reported, and it is now the default `--scorer`. The NLI model rejects almost every claim
(passages are long and claims are paraphrased), so its rates below are not meaningful.
Caveat: the audit has only 3 unfaithful examples, so the judge's ability to catch an
unfaithful answer rests on 3 items.

## 2. Faithfulness rate of answered questions (`answers__faithfulness_*_test.json`)

Share of answered test questions whose answer is supported by the passages shown to the
model. 95% Wilson intervals.

| Scorer | M1 baseline (BM25, n=79) | BM25 RAG (n=86) | Full system (n=88) |
|---|---|---|---|
| **qwen2.5:7b judge** | **81.0%** (71.0-88.1) | **90.7%** (82.7-95.2) | **86.4%** (77.7-92.0) |
| Lexical | 32.9% | 65.1% | 62.5% |
| NLI | 6.3% | 11.6% | 9.1% |

The full system is not significantly more faithful than the baseline (intervals overlap),
and its point estimate (86.4%) is below the project's >90% grounded-answer target, so the
target is **not met**.

## 3. Correctness: judge vs keyword grading (`answers__correctness_test.json`)

All 92 answerable test questions per system. Keyword accuracy is the headline metric in
the README; the judge is a second opinion.

| System | Keyword accuracy | Judge accuracy | Agreement | Kappa |
|---|---|---|---|---|
| M1 baseline | 77.2% | 68.5% | 91.3% | 0.78 |
| BM25 RAG | 80.4% | 73.9% | 89.1% | 0.69 |
| Full system | 87.0% | 77.2% | 90.2% | 0.67 |

The two graders disagree on 27 of 276 answers. Claude (not a clinician) read every one
against the question and answer; the verdicts are below.

| Who was right | Count | Answers |
|---|---|---|
| Keywords (judge too strict: a full, correct answer marked INCORRECT) | 17 | m1: q027, q060, q062, q072, q077, q089; bm25: q008, q009, q027, q072, q123, q131; full: q009, q047, q072, q080, q089 |
| Judge, keyword false positive (the keyword appears, the answer is wrong) | 4 | m1: q020 (says 38%, 76% only in passing), q138 (does not pick fasting glucose); full: q096 (contradictory mortality figures), q123 (says 40%) |
| Judge, keyword false negative (right answer in another form) | 2 | bm25: q075 ("80.6%"), q078 ("elevated") |
| Unclear (partly right) | 4 | bm25 and full: q018 (right only for older patients), q060 (SIRT1 only, nothing on Klotho) |

Adjudicated accuracy (keyword grading corrected by these 27 reads, the unclear ones
counted wrong): M1 baseline **75.0%** (69/92), BM25 RAG **80.4%** (74/92), full system
**82.6%** (76/92). Keyword grading therefore overstates the full system by about 4 points
(87.0% → 82.6%), and the gain over the baseline shrinks from +9.8 to +7.6 points. The judge
is too strict to replace keyword grading: it was wrong in 17 of the 27 disagreements and
right in 6.

## 4. Every test answer labeled by hand (added later the same day)

The 20-item audit above has only 3 unfaithful answers, so it says little about how well a
judge catches them. All 88 answered test questions of the full system were then labeled by
hand, blind to every judge's verdicts: each answer sentence was read against the passages
shown to the model (`eval/qa/faithfulness_labels_test.json`, reviewer Claude, not a
clinician; citation numbers ignored, since citation accuracy is measured separately).

**Hand-labeled faithfulness of the full system: 78/88 = 88.6% (95% CI 80.3-93.7).** The ten
unfaithful answers: four attach a number to the wrong group or measure (q014, q044, q096,
q123), four add claims the passages do not make (a study limitation, outside knowledge,
a trend by age, unstated sources: q045, q098, q126, q072), one says the passages have no
information they do have (q060), and one reverses a finding (q078, "dose-dependent").

Each scorer against those 88 labels (`python -m healthcare_rag.judge labels <run.json>`;
raw runs in `labels_check_*.json`):

| Scorer | Rate | Agreement | Kappa | Faithful matched | Unfaithful caught |
|---|---|---|---|---|---|
| **qwen2.5:7b, one-word verdict (the default)** | 86.4% | **90.9%** | **0.58** | 73/78 | **7/10** |
| qwen2.5:7b, also given the question (`judge_q`) | 85.2% | 87.5% | 0.45 | 71/78 | 6/10 |
| qwen2.5:7b, claim by claim with quotes (`claims`) | 83.0% | 83.0% | 0.31 | 68/78 | 5/10 |
| gemma3:4b, one-word verdict | 97.7% | 90.9% | 0.31 | 78/78 | 2/10 |

- The one-word judge is still the best automatic scorer, but on the full set its kappa is
  0.58, not the 0.83 the small audit suggested. It misses 3 of 10 unfaithful answers and
  rejects 5 faithful ones (q089, q104, q105, q114, q134: verbatim or near-verbatim answers).
  Its errors roughly cancel here (86.4% vs 88.6%), but it should be read as ±a few points.
- Asking the 7B model to list claims and quote support first made it worse: it often
  skipped the format, declared verbatim answers NOT FOUND, or quoted the right sentence and
  still said YES to a reversed claim (q078).
- gemma3:4b says YES to almost everything.

So the faithfulness target is judged by the hand labels from here on, with the one-word
judge as a cross-check.
